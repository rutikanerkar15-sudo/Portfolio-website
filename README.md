# Portfolio Website

A multi-page, responsive developer portfolio built using HTML5, CSS3, and JavaScript.

## 🚀 Live Demo
**Live Website:** [https://rutikanerkar15-sudo.github.io/Portfolio-website/](https://rutikanerkar15-sudo.github.io/Portfolio-website/)

---

## Features
* **Responsive Navigation:** Clean navigation bar across all pages with custom SVG icons.
* **Theme Switcher:** Dark/Light mode toggle powered by JavaScript and CSS custom properties.
* **Interactive Project Filtering:** Filter projects dynamically by category (Backend / Full-Stack).
* **Resume Download:** Direct access to download the candidate's PDF resume.
* **Contact Form:** Structured HTML5 contact form with field validations.

---

## Tech Stack
* **HTML5** (Semantic Structure)
* **CSS3** (Flexbox, CSS Grid, Custom Variables)
* **JavaScript** (ES6+, LocalStorage, DOM Manipulation)
